> 메카를 출격시키고, 프로토콜 메카로 전세를 뒤집어 오염된 순천만을 구하세요.

**메카히어로즈**는 순천만을 배경으로 한 **2D 횡스크롤 디펜스 게임**입니다. 
자동으로 쌓이는 골드를 활용해 메카를 생산하고 전력을 강화하며, 아군 기지를 지키는 동시에 적 기지를 파괴하는 것이 목표입니다. 
순천만의 생태와 전대물에서 착안한 메카 디자인을 캐주얼한 그래픽으로 담았습니다.

| 항목 | 내용 |
| --- | --- |
| 프로젝트 | 2025AIGameJam |
| 장르 | 2D 횡스크롤 디펜스 |
| 배경 | 순천만 |
| 엔진 / 언어 | Unity 2022.3.62f1 / C# |
| 기본 화면 설정 | 1920 × 1080, 16:9 |
| 게임 씬 | Title, Stage1, Stage2, Stage3 |

## 세계관

2025년, 인류의 무관심이 낳은 가스가 순천만을 뒤덮습니다. 평화롭게 살아가던 동물들은 괴물로 변해 자신들의 터전을 파괴하기 시작합니다.

위기에 처한 주인공 앞에 나타난 것은 거대한 메카와 파일럿 **천순**. 그녀의 도움으로 새로운 메카 파일럿이 된 주인공은 순천만을 되찾기 위한 전투에 나섭니다.

## 플레이 방식

1. **스테이지 선택**: 타이틀에서 게임을 시작하고 전투할 스테이지를 선택합니다.
2. **메카 생산**: 골드와 유닛별 생산 쿨타임을 확인하며 메카를 출격시킵니다. 출격한 유닛은 자동으로 이동하고 적을 공격합니다.
3. **전력 강화**: 골드를 투자해 수입과 최대 보유량을 늘리거나 아군 메카의 공격력을 강화합니다.
4. **프로토콜 발동**: 적 유닛에게 피해를 주어 프로토콜 게이지를 모으고, 이를 소모해 강력한 프로토콜 메카를 소환합니다.
5. **기지 공략**: 적 기지의 체력을 0으로 만들면 승리합니다. 아군 기지의 체력이 먼저 소진되면 패배합니다.

### 주요 시스템

- **생산과 성장의 선택**: 당장 병력을 늘릴지, 이후 전투를 위해 경제와 공격력에 투자할지 결정합니다.
- **다양한 공격 방식**: 근접·원거리, 단일·범위 공격을 지원하는 유닛 전투 구조를 사용합니다.
- **프로토콜 메카**: 일반 골드와 별도의 전투 자원을 사용하는 특수 유닛입니다. 현재 데이터 기준 게이지 1,000을 소모하며, 소환 쿨타임은 60초입니다.
- **3개 스테이지**: Stage1부터 Stage3까지 전투 씬이 구성되어 있습니다.
- **캐릭터 도감과 연출**: 메카·몬스터 도감, 인트로 컷신, UI 전환 애니메이션, BGM·효과음을 포함합니다.

### 조작

| 입력 | 동작 |

| 마우스 왼쪽 클릭 | 메뉴·스테이지 선택, 메카 구매, 강화, 프로토콜 소환 |
| 마우스 왼쪽 드래그 | 전장 카메라 좌우 이동 |

## 실행 방법

### Unity 에디터에서 실행

1. 저장소를 복제합니다.

   ```bash
   git clone https://github.com/SungJieundev/2025AIGameJam.git
   ```

2. Unity Hub에서 **Unity 2022.3.62f1**을 준비합니다.
3. 복제한 저장소 안의 **`2025AIGameJam` 하위 폴더**를 프로젝트로 추가합니다. `Assets`, `Packages`, `ProjectSettings`가 들어 있는 폴더입니다.
4. 패키지 복원과 에셋 임포트가 완료되면 `Assets/00. Scenes/Title.unity`를 엽니다.
5. 에디터의 **Play** 버튼으로 시작합니다. Game 뷰는 **16:9**로 설정하는 것을 권장합니다.

타이틀에서 공용 UI와 오디오를 초기화하므로, 정상적인 플레이 흐름을 확인할 때는 타이틀 씬에서 시작하세요.

### 빌드

`File > Build Settings`에서 대상 플랫폼을 선택하고 필요한 Unity 빌드 모듈을 설치합니다. 현재 빌드 설정의 씬 순서는 다음과 같습니다.

```text
0  Assets/00. Scenes/Title.unity
1  Assets/00. Scenes/Stage1.unity
2  Assets/00. Scenes/Stage2.unity
3  Assets/00. Scenes/Stage3.unity
```

## 기술 구성

| 구성 | 용도 |
| --- | --- |
| Unity / C# | 게임 로직, 씬 구성, 2D 물리 |
| URP 14.0.12 | 렌더링 파이프라인 |
| TextMeshPro 3.0.7 / Unity UI | 재화·체력 표시, 메뉴와 인게임 UI |
| DOTween / DOTween Pro | 패널 이동, 팝업, 페이드 등 연출 |
| ScriptableObject | 유닛 능력치와 오브젝트 풀 초기 구성 |

### 코드 구조

| 영역 | 주요 구성과 역할 |
| --- | --- |
| 게임 진행 | `GameManager`: 재화 수급, 강화, 프로토콜 자원, 승패 처리 |
| 유닛 상태 | `UnitBase`, `StateMachine`: 생성 → 이동 → 공격 → 사망 상태 전환 |
| 공격 동작 | `IAttackBehaviour`, `AttackFactory`: 공격 유형별 동작 분리 |
| 유닛 데이터 | `UnitSO`, `UnitStat`: 기본 능력치와 전투 중 능력치 관리 |
| 생산 | `TowerSpawner`, `EnemySpawner`: 아군 구매·소환과 적 생성 |
| 재사용 | `PoolManager`: 유닛·투사체 등 풀링 대상 오브젝트 관리 |
| 화면·사운드 | `UIManager`, `InGameUI`, `AudioManager`: 화면 전환, 전투 정보, 오디오 관리 |

```text
2025AIGameJam/
├── Assets/
│   ├── 00. Scenes/      # 타이틀, 스테이지, 테스트 씬
│   ├── 01. Scripts/     # Core, FSM, Interface, System, Tower, Enemy
│   ├── 02. Sprites/     # 캐릭터, 배경, UI 이미지
│   ├── 03. Animation/   # 애니메이션
│   ├── 04. Sound/       # BGM, 효과음
│   ├── 05. So/          # 유닛·풀링 설정 데이터
│   ├── 06.Fonts/        # 폰트
│   ├── 07. Prefab/      # 프리팹
│   └── Plugins/         # DOTween 등
├── Packages/
└── ProjectSettings/
```

## 기획과 구현 기준

세계관과 그래픽 방향은 메카히어로즈 컨셉 기획서를, 시스템과 실행 안내는 현재 소스 코드 및 프로젝트 설정을 기준으로 작성했습니다.

기획서의 프로토콜은 미션·조건 달성을 통한 발동을 구상했으며, 현재 코드는 **적 유닛에게 준 피해량으로 게이지를 충전하는 방식**입니다. 
기획서의 유닛 가격과 명칭 등은 개발 과정에서 달라질 수 있으며, 실제 수치는 `Assets/05. So/`의 데이터를 따릅니다.
